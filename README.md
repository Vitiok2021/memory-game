# Memory Game

A simple, classic Memory Game built with Vanilla JavaScript for the RS School course. The goal of the game is to find all matching pairs of cards using the minimum number of moves.

## Features

- **Vanilla JavaScript:** The entire interface (all HTML elements) and game logic are generated purely via JavaScript using `document.createElement`, without any third-party libraries.
- **Leaderboard:** Saves your top 10 best scores (least amount of moves) using the browser's `localStorage`. Your results remain even after refreshing the page.
- **Dynamic Gameplay:** Real-time move counter, match tracking, and random card reshuffling upon starting a new game.
- **Custom Modals:** Custom modal window implementation for the victory screen and leaderboard, closable via the close button, clicking on the dark background overlay, or pressing the `Escape` key.

## How to run locally

This project requires no build tools or servers. To run it locally:

1. Clone this repository to your local machine.
2. Navigate to the project folder.
3. Open the `index.html` file in any modern web browser (Google Chrome, Firefox, Safari, etc.).
